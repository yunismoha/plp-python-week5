# PLP Python Week 5 - Countdown, Guessing Game & Loop Patterns

* `countdown.py` - Uses a while loop to count down from a number and print "Blast off!".
* `guess_game.py` - Uses a while loop, conditionals, and an attempt counter to create a guessing game.
* `spell_it_out.py` - Uses for loops to display the letters of a word individually and with numbers.
* `screenshots/` - Contains screenshots showing the programs running.

I would use a `while` loop when I do not know exactly how many times the loop needs to run, such as a guessing game that continues until the user gets the correct answer. I would use a `for` loop when I need to go through a known collection of items, such as each letter in a word.
